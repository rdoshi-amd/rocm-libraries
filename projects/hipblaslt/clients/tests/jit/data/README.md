# Pre-generated JIT test bundles

Each directory under `gfx950/` is one source bundle: the input a JIT backend
returns and the comgr builder builds. The JIT tests build and load these
bundles, so they need neither Python nor a generator.

| Path | Contents |
| --- | --- |
| `library/TensileLibrary.dat` | The one-solution library entry (MsgPack, uncompressed) |
| `sources/<kernel>.s` | The main kernel assembly; exactly one |
| `manifest.json` | Provenance; hipBLASLt does not read it |

The manifest names the main kernel (`main_kernel.name`), the solution, the
library path and format, and the sources. Its `provenance` object records
`source_revision`, `generator_version`, `compiler_version`, `code_object_version`,
`kernargs_version` and `persistent_loop_args_version`.

| Bundle | Problem and execution policy | Generator command |
| --- | --- | --- |
| `gfx950/plain` | FP16 A, B, C and D, FP32 compute, A and B not transposed; one wave64 per 16x16 tile, K in steps of 16, no prefetch; GlobalSplitU=1, TileProcessingStrategy=None; no helper kernels | `python -m Tensile.SingleSolution ../clients/tests/jit/data/plain.yaml OUT --architecture gfx950 --cxx-compiler amdclang++ --source-only` (`OUT/bundle`) |

The files are TensileLite output (MIT licence), generated by the command above
from `plain.yaml` in this directory and the TensileLite sources at the
manifest's `source_revision`. The command runs in
`projects/hipblaslt/tensilelite` with `OUT` a fresh directory and `PYTHONPATH`
naming the `tensilelite/rocisa` and `tensilelite` directories of a
hipBLASLt build and then `projects/hipblaslt/tensilelite`; the bundle is the
named directory under `OUT`. The bundle is copied without symbolic links, and
`provenance.compiler_path` is removed from its manifest. The generator writes
the library entry compressed, as `library/TensileLibrary.dat.zlib`; it is
stored inflated as `library/TensileLibrary.dat`, and the manifest's
`library.path` names that file.

A bundle goes stale when its `kernargs_version` or `persistent_loop_args_version`
differs from `KernArgsVersion` or `PersistentLoopArgsVersion` in
`tensilelite/Tensile/Common/GlobalParameters.py`, or its `code_object_version`
differs from the version the JIT builder uses. Regenerate it with the change
that made it stale.
